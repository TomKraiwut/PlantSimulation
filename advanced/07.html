7. ควบคุมจากภายนอกผ่าน COM/Python

วัตถุประสงค์การเรียนรู้

  1. เชื่อมต่อ Plant Simulation จากภายนอกผ่าน COM ด้วย Python ได้
  2. รันโมเดลแบบ headless (ไม่มีหน้าต่างโปรแกรม) สำหรับงาน automation ได้
บทเสริม: บทนี้สำหรับผู้ที่ต้องการเชื่อมต่อ Plant Simulation จากภายนอกโปรแกรม เช่น เขียนสคริปต์ Python ควบคุมการรันแบบอัตโนมัติ (automation/integration) — ไม่จำเป็นสำหรับการใช้งานโปรแกรมทั่วไป

เชื่อมต่อแบบ Headless ผ่าน COM

Plant Simulation ลงทะเบียน COM ProgID เฉพาะแต่ละเวอร์ชันไว้ ตามรูปแบบ Tecnomatix.PlantSimulation.RemoteControl.<MAJOR>.<MINOR> เช่นเวอร์ชัน 2201 คือ Tecnomatix.PlantSimulation.RemoteControl.22.1 (สังเกตจุดคั่น ไม่ใช่ .2201)

ควรใช้ ProgID เฉพาะเวอร์ชันเสมอ: ProgID แบบทั่วไป (ไม่ระบุเวอร์ชัน) จะชี้ไปยังเวอร์ชันล่าสุดที่เพิ่งลงทะเบียนตัวเองเป็นค่าเริ่มต้น ซึ่งเปลี่ยนได้ตามการติดตั้ง — ถ้าต้องการความแน่นอนว่าเชื่อมต่อเวอร์ชันไหน ให้ระบุ ProgID แบบมีเลขเวอร์ชันเสมอ

การเชื่อมต่อขั้นต่ำใน Python (ใช้ pywin32)

import win32com.client

PROGID = "Tecnomatix.PlantSimulation.RemoteControl.22.1"

app = win32com.client.Dispatch(PROGID)
app.SetVisible(False)          # ไม่แสดงหน้าต่างโปรแกรมเลย
app.SetNoMessageBox(True)      # ปิด dialog ที่อาจค้างรอผู้ใช้กด
app.loadModel(r"C:\path\to\Model.spp")
# ... สั่งงานผ่าน ExecuteSimTalk ตามบทที่ 1-4 ...
app.Quit()                     # ปิดให้เรียบร้อยทุกครั้ง
กติการายละเอียด
SetVisible/SetNoMessageBox ต้องเรียกก่อน loadModelถ้าอยากให้การโหลดโมเดลเงียบสนิทตั้งแต่ต้น
ต้อง Quit() ทุกครั้งไม่ปิดจะมีโปรเซสค้างอยู่เบื้องหลังสะสมไปเรื่อยๆ
ExecuteSimTalk รับพารามิเตอร์เดียวคือ source code string — path ของ Object ต้องฝังอยู่ในสตริงโค้ดเอง ไม่ใช่พารามิเตอร์แยก

รันโค้ด SimTalk จาก Python

result = app.ExecuteSimTalk('->integer; return .Models.Model.NumNodes')
print(result)
คำถามฝึกคิด: ทำไมต้องเรียก Quit() ทุกครั้งแม้สคริปต์จะจบการทำงานแล้ว?
เฉลย: เพราะโปรเซส Plant Simulation ที่เปิดผ่าน COM เป็นโปรเซสจริงที่รันอยู่เบื้องหลัง (แม้ตั้ง SetVisible(False) ไว้ก็ตาม) ถ้าสคริปต์จบโดยไม่ปิดมัน โปรเซสจะยังค้างกินหน่วยความจำอยู่ และถ้ารันสคริปต์แบบนี้ซ้ำหลายรอบโดยไม่ Quit จะมีโปรเซสค้างสะสมเพิ่มขึ้นเรื่อยๆ
