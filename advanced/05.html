Plant Simulation Tutorial

5. Experiment Manager

วัตถุประสงค์การเรียนรู้

  1. ตั้งค่า Scenario หลายชุดใน Experiment Manager ได้
  2. เปรียบเทียบผลลัพธ์ระหว่าง Scenario เพื่อใช้ตัดสินใจได้

Experiment Manager คืออะไร

ใช้สำหรับรันโมเดลหลายๆ รอบด้วยค่าพารามิเตอร์ต่างกันโดยอัตโนมัติ (เช่น เปรียบเทียบจำนวนเครื่องจักร 2 vs 3 เครื่อง) แทนที่จะเปลี่ยนค่าแล้ว Reset แล้วรันเองทีละรอบ

ขั้นตอนตั้งค่า

  1. เปิด Experiment Manager จาก Class Library หมวด Tools
  2. เพิ่ม Scenario แล้วกำหนดค่าตัวแปร (Input) ที่จะเปลี่ยนในแต่ละรอบ — เช่น จำนวนสถานี, ProcTime, Capacity ของ Buffer
  3. กำหนดค่าที่ต้องการดูผลลัพธ์ (Output) เช่น Throughput, Utilization, StatDeleted ของ Drain
  4. กด Run All เพื่อรันทุก Scenario อัตโนมัติแล้วเปรียบเทียบผลในตารางเดียว
Tip: ตั้งชื่อ Scenario ให้สื่อความหมาย (เช่น 2_Machines, 3_Machines) แทนชื่อดีฟอลต์ Scenario1/2/3 — เมื่อ Scenario เยอะขึ้นจะอ่านผลเปรียบเทียบได้ง่ายกว่ามาก

ต่อยอดสู่ Optimization

Optimizer ต่อยอดจาก Experiment Manager โดยใช้ขั้นตอนวิธีค้นหาอัตโนมัติ (เช่น Genetic Algorithm ผ่าน GAWizard ดูบทที่ 6) แทนการกำหนด Scenario เองทีละชุด — เหมาะเมื่อพารามิเตอร์ที่ต้องปรับมีหลายตัวจนลองเองทุกชุดไม่ไหว

คำถามฝึกคิด: เมื่อไหร่ควรใช้ Experiment Manager ธรรมดา เมื่อไหร่ควรใช้ Optimizer/GAWizard?
เฉลย: ถ้าพารามิเตอร์ที่สนใจมีไม่กี่ตัวและมีชุดค่าที่ชัดเจนอยู่แล้ว (เช่น เทียบ 2 กับ 3 เครื่อง) ใช้ Experiment Manager ธรรมดาพอ ไล่ดูผลได้ตรงไปตรงมา — แต่ถ้าพารามิเตอร์มีหลายตัวและช่วงค่ากว้าง (เช่น หา Capacity ของ Buffer 5 จุดพร้อมกันที่ทำให้ Throughput สูงสุด) การไล่ลองเองทุกชุดจะใช้เวลานานเกินไป ควรใช้ Optimizer ให้ค้นหาแทน
