Plant Simulation Tutorial

6. Optimization ด้วย GAWizard

วัตถุประสงค์การเรียนรู้

  1. เข้าใจขอบเขตของ GAWizard และวิธีตั้งค่าผ่าน GUI
  2. รู้ว่าเมื่อไหร่ควรใช้ GAWizard กับเมื่อไหร่ควรเขียน optimization เอง

GAWizard คืออะไร

GAWizard คือเครื่องมือ Optimization ด้วย Genetic Algorithm ที่มากับ Plant Simulation อยู่ในหมวด .Tools เช่นเดียวกับ BottleneckAnalyzer และ ExperimentManager

ข้อจำกัดสำคัญ: GAWizard เป็น Object ที่สร้างผ่าน GUI wizard เท่านั้น — เรียก .Tools.GAWizard.createObject(...) จากโค้ดตรงๆ จะ error ("'GAWizard' cannot be adopted by...") เอกสารทางการของ Siemens เองก็ยืนยันว่าขั้นตอนคือ "คลิก Tools บน toolbar แล้วแทรก GAWizard เข้าไปในโมเดล" — เป็นการกระทำผ่าน GUI ล้วนๆ ไม่มีทางสร้างผ่านสคริปต์เพียงอย่างเดียว

ขั้นตอนตั้งค่าผ่าน GUI

  1. เตรียม DataTable/Variable ที่เก็บพารามิเตอร์ที่จะให้ Optimize (ดูบทที่ 3 สำหรับวิธีสร้าง)
  2. คลิก Tools บน toolbar → แทรก GAWizard เข้าไปในโมเดล
  3. ลากตาราง/ตัวแปรที่ต้องการ Optimize ไปวางบน GAWizard พร้อมกดปุ่ม Shift ค้างไว้ (ตามที่คู่มือระบุ) หรือลาก Object ประเภท GA (GASelection, GASequence, GARangeAllocation, GASetAllocation) ไปวางแล้วแก้ไข configuration method ที่เกิดขึ้น
  4. กำหนดค่า Fitness function (สิ่งที่ต้องการ maximize/minimize เช่น Throughput)
  5. รัน GAWizard ให้ค้นหาค่าพารามิเตอร์ที่ดีที่สุดข้ามหลายเจเนอเรชัน

แอตทริบิวต์ที่ใช้บ่อยเมื่อมี instance แล้ว

แอตทริบิวต์ความหมาย
penaltyValueค่า fitness ที่ให้กับ individual ที่ parametrize แล้วล้มเหลว
DecimalSeparatorตัวคั่นทศนิยมในรายงาน (. หรือ ,)
lastGeneration4DuplicatesCheckจำนวนเจเนอเรชันที่เช็คไม่ให้ประเมินซ้ำ (-1 = เช็คทุกเจเนอเรชัน)
ShowRuntimeAtEnd, AskForSaveModel, ShowHTMLatEndตัวเลือกโหมด batch เท่านั้น
คำถามฝึกคิด: ถ้าต้องการสร้างโมเดล optimization ใหม่แบบอัตโนมัติทั้งหมดโดยไม่แตะ GUI เลย ทำได้ไหม?
เฉลย: การใช้ GAWizard ของแท้ทำไม่ได้ (ข้อจำกัดข้างบน) แต่มีทางเลือก: (1) เตรียม instance ที่ config ไว้แล้วในโมเดลอื่น แล้ว duplicate/derive มันแทนการสร้างใหม่จาก class template หรือ (2) เขียน Optimization "ด้วยมือ" เองทั้งหมดจาก DataTable/Variable/Method (fitness, selection, mutation) ตามที่เรียนในบทที่ 3-4 ซึ่งเป็นการ reimplement สิ่งที่ GAWizard ทำให้อัตโนมัติ แทนที่จะใช้ตัวสำเร็จรูป
