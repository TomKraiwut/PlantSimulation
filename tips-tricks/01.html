Plant Simulation Tutorial

1. UI และ Workflow

วัตถุประสงค์การเรียนรู้

  1. รู้ทางลัดที่ช่วยให้ทำงานกับโปรแกรมเร็วขึ้นในชีวิตประจำวัน

จำ Layout หน้าจอที่ชอบไว้

ถ้าเรียงพาเนลจนพอใจแล้ว บันทึก Layout ไว้ (ถ้าเวอร์ชันรองรับ) แทนที่จะจัดใหม่ทุกครั้งที่เปิดโปรแกรม

ใช้ Navigator แทนการไล่หา Object ด้วยตา

เมื่อโมเดลมี Object เยอะและซ้อน Frame หลายชั้น การพิมพ์ค้นหาใน Navigator เร็วกว่าการไล่คลิกหาเองมาก

ตั้งชื่อ Object ตั้งแต่วางครั้งแรก

อย่าปล่อยชื่อดีฟอลต์ (SingleProc1, SingleProc2) ไว้นาน — เปลี่ยนเป็นชื่อสื่อความหมายทันทีที่วาง ก่อนที่โมเดลจะใหญ่จนย้อนมาไล่เปลี่ยนทีหลังลำบาก

คลิกขวาก่อนเสมอเมื่อไม่แน่ใจ

เมนูคลิกขวาของแต่ละ Object มักมีทางลัดไปหน้าที่ต้องการ (Statistics, Reset, Duplicate) เร็วกว่าเปิด Attribute window แล้วไล่หาแท็บเอง
