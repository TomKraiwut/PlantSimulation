3. ประสิทธิภาพการรัน (Performance)

วัตถุประสงค์การเรียนรู้

  1. รู้เทคนิคที่ช่วยให้โมเดลใหญ่รันเร็วขึ้นโดยไม่กระทบผลลัพธ์

ปิดภาพเคลื่อนไหว/มุมมอง 3D เวลารันเก็บสถิติ

ถ้าไม่ต้องการดูภาพเคลื่อนไหวระหว่างรัน (เช่นตอนรันเก็บผลอย่างเดียว) ปิดการแสดงผล/ลดความเร็วแอนิเมชันจะรันเร็วขึ้นมาก โดยไม่กระทบผลลัพธ์เชิงตัวเลขเลย

ใช้ Experiment Manager แทนการรันมือซ้ำๆ

การรันหลาย Scenario ด้วยมือ (เปลี่ยนค่า → Reset → รัน → จด → ทำซ้ำ) ทั้งช้าและเสี่ยงพลาด — ให้ Experiment Manager รันและเก็บผลอัตโนมัติแทนเสมอเมื่อมีมากกว่า 2-3 Scenario

โมเดลใหญ่มาก: ทดสอบ logic ด้วยโมเดลย่อยก่อน

เวลาดีบัก Method หรือโครงสร้างใหม่ ทดสอบใน Frame เล็กๆ ที่มี Object แค่ไม่กี่ตัวก่อน แล้วค่อยย้ายไปใช้กับโมเดลเต็มขนาด — เร็วกว่ารอโมเดลใหญ่รันครบทุกครั้งที่แก้โค้ดทีละบรรทัด

ระวังสคริปต์ที่เปิด Plant Simulation ผ่าน COM ซ้ำโดยไม่ Quit

สคริปต์ automation ที่ลืม app.Quit() จะทิ้งโปรเซสค้างไว้เบื้องหลังทุกครั้งที่รัน สะสมจนกินทรัพยากรเครื่องไปเรื่อยๆ โดยไม่มีหน้าต่างให้เห็นเลย (ดู Advanced บทที่ 7)
