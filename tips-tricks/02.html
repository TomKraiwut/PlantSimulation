2. การสร้างโมเดลและดีบัก

วัตถุประสงค์การเรียนรู้

  1. รู้ข้อผิดพลาดที่มือใหม่เจอบ่อย และวิธีเช็คให้ไวก่อนเสียเวลาไล่บั๊กผิดจุด

เช็ค EventController ก่อนเสมอถ้ารันไม่ได้

อาการ "กด Start แล้วไม่มีอะไรเกิดขึ้นเลย" ส่วนใหญ่มาจากลืมวาง EventController — เช็คจุดนี้ก่อนสงสัยอย่างอื่น

Reset ก่อนรันใหม่ทุกครั้งที่เปลี่ยนค่า

ลืม Reset คือสาเหตุอันดับต้นๆ ที่ทำให้ผลวิเคราะห์ผิดเพี้ยน เพราะสถิติสะสมปนกับรอบก่อนหน้า

Blocked สูง = ปัญหาอยู่ปลายทาง ไม่ใช่ตัวเอง

ถ้า Object หนึ่ง Blocked บ่อย อย่าเพิ่งแก้ที่ตัวมันเอง — ให้ไล่ดูสถานีถัดไปที่มันส่งงานให้ก่อนเสมอ

StatDeleted ไม่ใช่ NumMU เวลาเช็คว่าถึงปลายทางหรือยัง

Drain ทำลายชิ้นงานทันทีที่รับเข้า ทำให้ NumMU เป็น 0 เสมอไม่ว่าโมเดลจะทำงานถูกหรือพัง — ใช้ StatDeleted (ตัวนับสะสม) แทน

ยังไม่มีชิ้นงานถึงปลายทาง ≠ โมเดลพัง

เช็ค EventController.SimTime ก่อนสรุปว่าพัง — บางโมเดลรันใกล้เคียงเวลาจริง ต้องรอเวลาจำลองสะสมมากพอก่อนชิ้นงานจะไหลถึงปลายสาย
