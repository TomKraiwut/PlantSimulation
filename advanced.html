Advanced: SimTalk และการควบคุมโมเดลด้วยสคริปต์

เมื่อสร้างโมเดลพื้นฐานได้แล้ว ขั้นต่อไปคือการใช้ SimTalk เพื่อควบคุมพฤติกรรมของโมเดลแบบละเอียด

1. SimTalk คืออะไร

SimTalk คือภาษาสคริปต์ของ Plant Simulation ใช้เขียนใน Object ประเภท Method เพื่อสั่งงาน กำหนดเงื่อนไข หรือดึง/เปลี่ยนค่าตัวแปรของ Object อื่นในโมเดล ไวยากรณ์คล้าย Pascal

ก่อนเริ่ม: สร้าง Method ได้จาก Class Library หมวด Basic Objects → Method ลากมาวางบน Frame แล้วดับเบิลคลิกเพื่อเปิด Editor เขียนโค้ด

2. ตัวอย่างโค้ด SimTalk เบื้องต้น

Method ง่ายๆ ที่พิมพ์ข้อความลง Console เมื่อถูกเรียก:

is
  ;
do
  print "Simulation started at: ", EventController.SimTime;

ตัวอย่างการอ่าน/เขียนค่าตัวแปรของ Object อื่น เช่น เปลี่ยน Processing Time ของ SingleProc ระหว่างรัน:

is
  var t: real;
do
  t := 8.5;
  SingleProc.procTime := t;
  print "New processing time set to ", t;

3. Event-based Method: onEntrance / onExit

ผูก Method เข้ากับ Object เช่น SingleProc ในช่อง ExecuteAt.Entrance หรือ ExecuteAt.Exit เพื่อสั่งให้ทำงานทุกครั้งที่มีชิ้นงานเข้า/ออกสถานีนั้น 

is
  var mu: object;
do
  mu := @;  -- @ หมายถึง MU (ชิ้นงาน) ที่กำลังผ่านสถานีนี้
  print "MU ", mu.name, " entered station";

4. Table & List

ใช้ Table เก็บข้อมูลแบบ 2 มิติ เช่น ตารางเวลาการมาถึงของวัตถุดิบ หรือผลลัพธ์การทดลอง เข้าถึงค่าด้วย Table[column, row] 

is
do
  Table[1,1] := "Order A";
  Table[2,1] := 120;   -- จำนวนชิ้น
  print Table[1,1], " qty=", Table[2,1];

5. Experiment Manager และ Optimizer

ใช้สำหรับรันโมเดลหลายๆ รอบด้วยค่าพารามิเตอร์ต่างกัน (เช่น เปรียบเทียบจำนวนเครื่องจักร 2 vs 3 เครื่อง)

  1. เปิด Experiment Manager จาก Class Library หมวด Tools
  2. เพิ่ม Scenario แล้วกำหนดค่าตัวแปร (Input) ที่จะเปลี่ยนในแต่ละรอบ
  3. กำหนดค่าที่ต้องการดูผลลัพธ์ (Output) เช่น Throughput, Utilization
  4. กด Run All เพื่อรันทุก Scenario อัตโนมัติแล้วเปรียบเทียบผล

Optimizer ต่อยอดจาก Experiment Manager โดยใช้ Genetic Algorithm ค้นหาค่าพารามิเตอร์ที่ดีที่สุดอัตโนมัติ แทนที่จะลองทีละ Scenario เอง

6. แนวคิด Object-Oriented ใน Plant Simulation

Plant Simulation รองรับการสร้าง Object แบบ Custom โดยการ "ห่อ" (encapsulate) Object พื้นฐานไว้ใน Frame เดียว แล้วลากไปไว้ใน Class Library ของตัวเอง เพื่อนำกลับมาใช้ซ้ำ (Reusable Module) เช่น สร้าง "สถานีมาตรฐาน" ที่มี Buffer + SingleProc + สถิติในตัว แล้วใช้ซ้ำได้หลายจุดในโมเดลใหญ่

Tip: ตั้งชื่อตัวแปรและ Method เป็นภาษาอังกฤษและสื่อความหมายเสมอ เพราะเมื่อโมเดลใหญ่ขึ้น การดีบักผ่าน Console จะง่ายกว่ามาก
