Plant Simulation Tutorial

5. Chart และ Bottleneck Analyzer

วัตถุประสงค์การเรียนรู้

  1. อ่านผัง Sankey และสีของ Statistics ได้ถูกต้อง
  2. ใช้ Bottleneck Analyzer หาสถานีที่เป็นคอขวดของสายการผลิตได้

อ่านผัง Sankey

Plant Simulation แสดงเส้นทางการไหลของชิ้นงานเป็นผัง Sankey ได้ — เส้นยิ่งหนายิ่งมีปริมาณชิ้นงานไหลผ่านมาก ช่วยเห็นภาพรวมเส้นทางที่มีปริมาณงานสูงได้เร็วกว่าดูตัวเลขในตาราง

สีของ Statistics

สี (ทั่วไป)สถานะ
🟢 เขียวWorking — กำลังทำงาน
🟡 เหลืองWaiting — ว่างงาน รอชิ้นงาน
🔴 แดงBlocked — ทำเสร็จแล้วแต่ส่งต่อไม่ได้
⚫ ดำ/เทาเข้มFailed/Down — เครื่องเสีย (ถ้าตั้ง Failure ไว้ตามบทที่ 4)

สีที่แน่นอนปรับได้จากการตั้งค่าโปรแกรม แต่แนวคิด "ยิ่งแดง/ดำเยอะยิ่งมีปัญหา" ใช้ได้เสมอ

ใช้ Bottleneck Analyzer

  1. เปิดจาก Class Library หมวด Tools → BottleneckAnalyzer ลากมาวางในโมเดล
  2. เชื่อมโยง/เลือก Object ที่ต้องการวิเคราะห์ (มักเลือกทั้งสายการผลิต)
  3. รันซิมูเลชันตามปกติ จากนั้นเปิดรายงานของ BottleneckAnalyzer
  4. อ่านผล — เครื่องมือจะจัดอันดับสถานีที่เป็นคอขวด (มักดูจากสัดส่วนเวลา Blocked/Waiting สูงสุด) ให้อัตโนมัติ แทนที่จะไล่ดูทีละสถานีเอง
Tip: Bottleneck ที่แท้จริงอาจไม่ใช่สถานีที่ดูยุ่งที่สุด — สถานีที่ค่า Working สูงสุดอาจแค่ "ทำงานหนัก" ในขณะที่ตัวจริง คือสถานีที่ทำให้สถานีอื่น Blocked บ่อยที่สุดต่างหาก ใช้ Bottleneck Analyzer แทนการเดาเอง
คำถามฝึกคิด: Export ผลจาก Bottleneck Analyzer หรือ Chart ไปใช้ต่อ (เช่น ทำรายงานให้หัวหน้า) ทำได้ไหม?
เฉลย: ได้ — Chart ส่วนใหญ่ใน Plant Simulation คลิกขวาแล้วมีตัวเลือก Export เป็นรูปภาพหรือคัดลอกข้อมูลตารางออกไปวางในโปรแกรมอื่นได้
