Plant Simulation Tutorial

1. Object ขั้นกลาง

วัตถุประสงค์การเรียนรู้

  1. แยกความแตกต่างของ Buffer/Store, AssemblyStation, Track และ Transporter ได้
  2. เลือกใช้ Object ที่เหมาะกับสถานการณ์ในโมเดลจริงได้

Object ขั้นกลางที่ใช้บ่อย

Objectใช้ทำอะไรต่างจากตัวพื้นฐานอย่างไร
Bufferพักชิ้นงานแบบ FIFO เรียบง่ายเทียบกับ Store: Buffer ไม่มีตำแหน่งจัดเก็บย่อย เข้าก่อนออกก่อนเสมอ
Storeพักชิ้นงานแบบมีตำแหน่ง/ชั้นวางย่อย ดึงออกไม่ต้องเรียงลำดับเหมาะจำลองคลังสินค้า/ชั้นวางจริงที่หยิบสินค้าจากตำแหน่งใดก็ได้
AssemblyStationรวมชิ้นงานจากหลายทางเข้าเป็นชิ้นเดียว (เช่น ประกอบชิ้นส่วน A+B)Station รับ-ส่งทางเดียว แต่ AssemblyStation รอครบทุกอินพุตก่อนประมวลผล
Trackเส้นทางที่ให้ Transporter วิ่งบนนั้น (ต่างจาก Conveyor ที่ขนส่งอัตโนมัติ)ใช้คู่กับ Transporter เพื่อจำลองรถขนส่ง/AGV ที่ขับเคลื่อนเอง
Transporterพาหนะขนส่งชิ้นงานที่ขับเคลื่อนไปมาเองบน Track (อยู่ในหมวด MU ไม่ใช่ MaterialFlow)ต่างจาก Conveyor ตรงที่ Transporter เป็นวัตถุเดี่ยวที่ต้องวิ่งไปรับ-ส่งเอง ไม่ใช่สายพานตายตัว
เลือกใช้อย่างไร: ถ้าของแค่ "พักคอย" ธรรมดา ใช้ Buffer พอ — ถ้าต้องจำลองคลังที่หยิบแบบสุ่มตำแหน่งได้ ใช้ Store — ถ้าต้องรวมชิ้นส่วนหลายทางเป็นหนึ่งเดียว (ประกอบสินค้า) ใช้ AssemblyStation — ถ้ามีรถ/พาหนะขนส่งเอง ใช้ Track + Transporter

ตัวอย่าง: จำลองสถานีประกอบ

โครงสร้าง: Source1(ชิ้นส่วน A) → AssemblyStation ← Source2(ชิ้นส่วน B) จากนั้น AssemblyStation → Drain

คำถามฝึกคิด: ถ้า Source1 ผลิตเร็วกว่า Source2 มาก จะเกิดอะไรขึ้นที่ AssemblyStation?
เฉลย: ชิ้นส่วนจาก Source1 จะสะสมรอที่ทางเข้า AssemblyStation เพราะสถานีต้องรอให้ชิ้นส่วนจาก Source2 มาครบคู่ก่อนจึงประมวลผลได้ — ควรใส่ Buffer ก่อน AssemblyStation ด้านที่เร็วกว่า เพื่อไม่ให้ Source1 ถูก Block
