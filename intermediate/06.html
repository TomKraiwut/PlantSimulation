6. จัดกลุ่มโมเดลเป็น Sub-frame

วัตถุประสงค์การเรียนรู้

  1. ห่อกลุ่ม Object เป็น Sub-frame และเชื่อมพอร์ตเข้า-ออกได้
  2. นำโมดูลที่ห่อไว้กลับมาใช้ซ้ำในโมเดลอื่นได้

แนวคิด Sub-frame

เมื่อโมเดลใหญ่ขึ้น การมี Object เดี่ยวๆ กระจัดกระจายเต็ม Frame เดียวจะดูแลยาก — Plant Simulation ให้ "ห่อ" กลุ่ม Object ที่ทำงานร่วมกันไว้ใน Frame ย่อย (Sub-frame) เดียว แล้วมองจากภายนอกเหมือนเป็น Object ก้อนเดียว

สร้าง Sub-frame

  1. เลือก Object หลายตัวที่ต้องการห่อรวมกัน (เช่น Buffer + SingleProc + สถิติที่เกี่ยวข้อง)
  2. คลิกขวา → มองหาตัวเลือกลักษณะ "Group" หรือ "Move to new Frame" (ชื่อเมนูอาจต่างกันเล็กน้อยตามเวอร์ชัน)
  3. Object ที่เลือกจะถูกย้ายเข้าไปอยู่ใน Frame ใหม่ และ Frame นั้นแสดงเป็น Object ก้อนเดียวใน Frame แม่
  4. เพิ่ม Interface object (จุดเชื่อมต่อเข้า-ออก) ที่ขอบของ Sub-frame เพื่อให้ภายนอกเชื่อมต่อกับ Sub-frame นี้ได้เหมือน Object ปกติ

ทำให้นำกลับมาใช้ซ้ำได้

เมื่อ Sub-frame ทำงานตามต้องการแล้ว ลากมันเข้าไปเก็บไว้ใน Class Library หมวด UserObjects ของตัวเอง — จากนั้นจะสามารถลากมาวางซ้ำได้หลายจุดในโมเดลเดียวกัน หรือคัดลอกไปใช้ในโมเดลอื่น เหมือน "สถานีมาตรฐาน" สำเร็จรูป

Tip: ตั้งชื่อ Sub-frame และ Interface object ให้สื่อความหมายชัดเจน (เช่น In/Out สำหรับจุดเชื่อมต่อ) เพราะเมื่อนำไปใช้ซ้ำในโมเดลอื่น คนอื่นจะไม่เห็นรายละเอียดภายในทันที ต้องเข้าใจจากชื่อและพอร์ตที่เห็นจากภายนอก
คำถามฝึกคิด: ทำไมการห่อเป็น Sub-frame ถึงช่วยเรื่อง "reusable module" มากกว่าการ copy-paste Object กลุ่มเดิมซ้ำๆ?
เฉลย: เพราะ Sub-frame ที่เก็บใน UserObjects เป็นแม่แบบเดียวที่อ้างอิงร่วมกัน — ถ้าต้องแก้ไขพฤติกรรมภายใน (เช่น เพิ่มสถิติใหม่) แก้ที่แม่แบบเดียวจบ ขณะที่ copy-paste ต้องไล่แก้ทุกจุดที่เคยคัดลอกไว้แยกกัน
