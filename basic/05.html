Plant Simulation Tutorial

5. รันและอ่านผล Statistics

วัตถุประสงค์การเรียนรู้

  1. รันและ Reset ซิมูเลชันได้อย่างถูกวิธี
  2. อ่านและตีความค่า Working / Waiting / Blocked ได้

รัน / หยุด / รีเซ็ต

ปุ่มทำอะไร
Start (▶)เริ่มเดินเวลาจำลอง ตาม EventController
Stop/Pause (⏸)หยุดชั่วคราว กด Start ต่อได้จากจุดเดิม
Reset (⟲)ล้างค่าสถิติและตำแหน่งชิ้นงานทั้งหมด กลับสู่เวลา 0
ข้อควรระวัง: อย่าลืมกด Reset ก่อนรันใหม่ทุกครั้งที่เปลี่ยนค่าพารามิเตอร์ ไม่งั้นค่าสถิติจะสะสมปนกับรอบก่อนหน้า ทำให้ผลวิเคราะห์ผิดพลาด

อ่านผลลัพธ์เบื้องต้น

คลิกขวาที่ Object ประเภทประมวลผล (เช่น Station) แล้วเลือก Statistics เพื่อดู:

สถานะความหมาย
Workingเวลาที่เครื่องกำลังแปรรูปชิ้นงานจริง — ยิ่งสูงยิ่งใช้งานคุ้ม
Waitingเวลาที่รอชิ้นงานเข้ามา (ว่างงาน) — สูงแปลว่าต้นทางป้อนช้าเกินไป
Blockedเวลาที่ทำงานเสร็จแล้วแต่ส่งต่อไม่ได้ (สถานีถัดไปไม่ว่าง) — สูงแปลว่าปลายทางเป็นคอขวด
คำถามฝึกคิด: ถ้า Station มีค่า Blocked สูงมาก ควรแก้ปัญหาที่ตัว Station นี้เอง หรือที่อื่น?
เฉลย: ควรแก้ที่ สถานีถัดไป (ปลายทางที่รับต่อ) ไม่ใช่ตัว Station เอง — เพราะ Blocked สูง แปลว่าสถานีนี้ทำงานเสร็จเร็วกว่าที่ปลายทางจะรับได้ ปลายทางต่างหากที่เป็นคอขวดจริง
