05. หลายรุ่น + งานเสีย + Method แรก

วัตถุประสงค์การเรียนรู้

  1. ปล่อยงานหลายรุ่นตามตารางและแยกงานดี/งานเสียได้
  2. เขียน Method สั้นๆ ครั้งแรกเพื่อนับงานเสีย
กำลังจัดทำ: บทนี้กำลังเรียบเรียงเป็นแบบ Step by Step บน Plant Simulation 2606 พร้อมภาพหน้าจอทีละขั้น — ด้านล่างคือโครงหัวข้อของบทที่จะได้เรียน

หัวข้อในบทนี้

  1. สร้าง MU 3 รุ่น (A / B / C) ใน Class Library สีต่างกัน
  2. Source ปล่อยงานตามตาราง (DataTable: รุ่น, จำนวน)
  3. Station ใช้เวลาต่างกันตามรุ่น
  4. Station5 ส่งงานดี 95% ไป Drain และงานเสีย 5% ไป Rework
  5. Method แรก: นับงานเสียลง Variable แล้วแสดงบน Display
  6. Sankey Diagram ดูทางเดินของงาน

Frame ในไฟล์ของบท

ไฟล์ .spp ของบทมีหลาย Frame เล่าเรื่องเดียวกัน — เปิดไฟล์ของบทได้เลย ไม่ต้องทำบทก่อนหน้าให้เสร็จ:

Model 1 รุ่น · Model2 3 รุ่นตามตาราง · Model3 + งานเสีย / Rework + Method

บทนี้เป็นบทแรกที่เขียนโค้ด SimTalk (Method 5–10 บรรทัด) — ดูพื้นฐาน syntax ได้ที่ Advanced บทที่ 1
