6. บันทึกและเปิดไฟล์โมเดล

วัตถุประสงค์การเรียนรู้

  1. บันทึกไฟล์โมเดล (.spp) และเปิดไฟล์เดิมกลับมาทำต่อได้
  2. มีนิสัยสำรองไฟล์ที่ปลอดภัย ก่อนไฟล์เสียหรือหาย

บันทึกไฟล์โมเดล

Plant Simulation บันทึกไฟล์เป็นนามสกุล .spp — ไฟล์เดียวเก็บทั้งโมเดล, Frame ย่อยทั้งหมด, และ Class Library ที่ปรับแต่งเอง

  1. Ctrl+S หรือเมนู File → Save — บันทึกทับไฟล์เดิม
  2. File → Save As — บันทึกเป็นไฟล์ใหม่ (แนะนำเมื่อจะทดลองอะไรเสี่ยงๆ กับโมเดล)
  3. File → Open — เปิดไฟล์ .spp ที่มีอยู่กลับมาทำต่อ
ข้อควรระวังเรื่องเวอร์ชัน: ไฟล์ที่บันทึกจากโปรแกรมเวอร์ชันใหม่กว่า จะเปิดไม่ได้ในโปรแกรมเวอร์ชันเก่ากว่า (ขึ้น error ประมาณ "model version is higher than the program version") — ถ้าทำงานร่วมกับคนอื่น ควรตกลงกันว่าใช้โปรแกรมเวอร์ชันเดียวกัน หรือรู้ว่าไฟล์ต้นทางเซฟจากเวอร์ชันไหน

นิสัยสำรองไฟล์ที่ควรมี

  • ก่อนทดลองเปลี่ยนโครงสร้างใหญ่ (เช่น ลบ Frame, แก้สคริปต์เยอะ) ให้ Save As เป็นไฟล์สำรองก่อน เช่น PLT_backup_2026-08-29.spp
  • ตั้งชื่อไฟล์ให้สื่อเวอร์ชัน/วันที่ แทนการเขียนทับไฟล์เดิมตลอด — ย้อนกลับได้เมื่อทำพลาด
  • ถ้าทำงานเป็นทีม เก็บไฟล์ไว้ในระบบที่มีประวัติการแก้ไข (เช่น โฟลเดอร์ที่ sync กับ cloud หรือ version control) ไม่ใช่แค่ในเครื่องเดียว
คำถามฝึกคิด: เพื่อนร่วมทีมส่งไฟล์ .spp มาให้ แต่เปิดไม่ได้ ขึ้น error เรื่องเวอร์ชัน ควรทำอย่างไรก่อน?
เฉลย: เช็คว่าเครื่องคุณติดตั้ง Plant Simulation เวอร์ชันเดียวกันหรือใหม่กว่าที่เพื่อนใช้เซฟหรือไม่ — ถ้าเครื่องมีหลายเวอร์ชันติดตั้งอยู่ ให้เปิดไฟล์ด้วยเวอร์ชันที่เท่ากับหรือใหม่กว่าเวอร์ชันที่บันทึกไฟล์นั้นไว้
