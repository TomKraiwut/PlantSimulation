Plant Simulation Tutorial

4. สร้างโมเดลแรก

วัตถุประสงค์การเรียนรู้

  1. ลากวางและเชื่อมต่อ Object เป็นสายการผลิตง่ายๆ ได้ด้วยตัวเอง
  2. ตั้งค่า Interval และ Processing Time ได้ถูกต้อง

สร้างโมเดลแรก: สายการผลิตง่ายๆ

ทำตามขั้นตอนนี้เพื่อสร้างโมเดล Source → Station → Drain

  1. เปิด Class Library → เลือกหมวด MaterialFlow
  2. ลาก Source, Station, Drain มาวางเรียงกันบน Frame
  3. ลาก EventController มาวางไว้มุมใดก็ได้ (จำเป็นต่อการรัน — ดูบทที่ 3)
  4. เชื่อมต่อ Object โดยคลิกที่มุมขวาบนของแต่ละ Object แล้วลากไปยัง Object ถัดไป (จะเห็นลูกศรเชื่อม)
  5. ดับเบิลคลิก Source เพื่อตั้งค่า Interval เช่น สร้างชิ้นงานทุก 5 วินาที
  6. ดับเบิลคลิก Station เพื่อตั้งค่า ProcTime เช่น 10 วินาทีต่อชิ้น
  7. กดปุ่ม Start Simulation (▶) ที่ Toolbar ด้านบน
Tip: ถ้าเชื่อมต่อ Object ไม่ติด ให้เช็คว่าจุดเชื่อม (Connector) เป็นสีเขียวหรือไม่ — สีแดงหมายถึงยังเชื่อมไม่สำเร็จ

ตัวอย่าง: ทำนายผลก่อนรันจริง

โมเดล Source(Interval=5s) → Station(ProcTime=10s) → Drain

คำถามฝึกคิด: Source ผลิตชิ้นงานเร็วกว่า Station แปรรูปเสร็จ (5s < 10s) จะเกิดอะไรขึ้นเมื่อรันไปนานๆ?
เฉลย: Station รับชิ้นงานไม่ทัน Source เลยจะถูก Blocked (สถานะรอส่งต่อ เพราะปลายทางไม่ว่าง) — นี่คือคอขวดแบบง่ายที่สุด แก้ได้ด้วยการเพิ่ม Buffer คั่นกลาง หรือเพิ่มสถานีขนาน (ดูบท Intermediate)
