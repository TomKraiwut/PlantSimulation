Basic: เริ่มต้นใช้งาน Plant Simulation

พื้นฐานที่ต้องรู้ก่อนสร้างโมเดลจำลองการผลิตแรกของคุณ

1. หน้าตาโปรแกรม (User Interface)

เมื่อเปิดโปรแกรมและสร้างไฟล์ใหม่ จะเจอส่วนหลักๆ ดังนี้

ส่วนประกอบหน้าที่
Class Libraryคลัง Object ทั้งหมดที่ใช้สร้างโมเดล เช่น MUs, Resources, Information Flow
Frameพื้นที่วาดโมเดล (เหมือน Canvas) ลาก Object มาวางและเชื่อมต่อกันที่นี่
Toolbarปุ่มควบคุมการรันซิมูเลชัน (Start, Reset, Speed)
Consoleแสดงข้อความ error/log ระหว่างรันหรือเขียนโค้ด

2. Object พื้นฐานที่ใช้บ่อย

Object เหล่านี้อยู่ใน Class Library หมวด MaterialFlow

Objectใช้ทำอะไร
Sourceจุดกำเนิดชิ้นงาน (MU) เข้าสู่ระบบ ตั้งค่าอัตราการผลิตได้
Line / Conveyorเส้นทางลำเลียงชิ้นงานระหว่างสถานี
SingleProc / Stationสถานีประมวลผล/แปรรูปชิ้นงาน (จำลองเครื่องจักร)
Bufferจุดพักชิ้นงานเมื่อสถานีถัดไปไม่ว่าง
Drainจุดสิ้นสุด ชิ้นงานออกจากระบบ (สินค้าสำเร็จรูป)
EventControllerตัวควบคุมเวลาจำลอง (นาฬิกาของโมเดล) ต้องมีเสมอในทุกโมเดล

3. สร้างโมเดลแรก: สายการผลิตง่ายๆ

ทำตามขั้นตอนนี้เพื่อสร้างโมเดล Source → SingleProc → Drain

  1. เปิด Class Library → เลือกหมวด MaterialFlow
  2. ลาก Source, SingleProc, Drain มาวางเรียงกันบน Frame
  3. ลาก EventController มาวางไว้มุมใดก็ได้ (จำเป็นต่อการรัน)
  4. เชื่อมต่อ Object โดยคลิกที่มุมขวาบนของแต่ละ Object แล้วลากไปยัง Object ถัดไป (จะเห็นลูกศรเชื่อม)
  5. ดับเบิลคลิก Source เพื่อตั้งค่า Interval เช่น สร้างชิ้นงานทุก 5 วินาที
  6. ดับเบิลคลิก SingleProc เพื่อตั้งค่า Processing Time เช่น 10 วินาทีต่อชิ้น
  7. กดปุ่ม Start Simulation (▶) ที่ Toolbar ด้านบน
Tip: ถ้าเชื่อมต่อ Object ไม่ติด ให้เช็คว่าจุดเชื่อม (Connector) เป็นสีเขียวหรือไม่ — สีแดงหมายถึงยังเชื่อมไม่สำเร็จ

4. ดูผลลัพธ์เบื้องต้น

คลิกขวาที่ SingleProc แล้วเลือก Statistics เพื่อดู:

  • Working — เวลาที่เครื่องทำงานจริง
  • Waiting — เวลาที่รอชิ้นงานเข้ามา (ว่างงาน)
  • Blocked — เวลาที่ทำงานเสร็จแล้วแต่ส่งต่อไม่ได้ (สถานีถัดไปไม่ว่าง)
ข้อควรระวัง: อย่าลืมกด Reset ก่อนรันใหม่ทุกครั้ง ไม่งั้นค่าสถิติจะสะสมต่อจากรอบก่อนหน้า
