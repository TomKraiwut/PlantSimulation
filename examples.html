Example File: ตัวอย่างโมเดลจริง

ฝึกทำตามตัวอย่างเหล่านี้เพื่อความเข้าใจที่ลึกขึ้น ไฟล์ .spp จริงสามารถอัปโหลดเพิ่มในโฟลเดอร์ /examples ของ repo นี้ได้

วิธีเพิ่มไฟล์ตัวอย่างจริง: สร้างโฟลเดอร์ examples/ แล้ววางไฟล์ .spp ของคุณลงไป จากนั้นใส่ลิงก์ดาวน์โหลดในหน้านี้ เช่น <a href="examples/line-01.spp">ดาวน์โหลด</a>

ตัวอย่างที่ 1: สายการผลิตเดี่ยว (Single Line)

โครงสร้าง: Source → Buffer → SingleProc → Drain

  • Source: สร้างชิ้นงานทุก 6 วินาที (Interval = 6s)
  • Buffer: ความจุ 10 ชิ้น
  • SingleProc: เวลาแปรรูป 8 วินาที/ชิ้น

คำถามฝึกคิด: เพราะ SingleProc ใช้เวลานานกว่า Source ผลิต (8s > 6s) จะเกิดอะไรขึ้นกับ Buffer เมื่อรันไปนานๆ?

เฉลย: Buffer จะเต็มเรื่อยๆ เพราะ SingleProc ระบายชิ้นงานออกช้ากว่าที่ Source ป้อนเข้ามา สุดท้าย Source จะถูก Block — นี่คือตัวอย่างคอขวด (Bottleneck) แบบง่ายที่สุด

ตัวอย่างที่ 2: สายการผลิตคู่ขนาน (Parallel Stations)

โครงสร้าง: Source → (SingleProc1 / SingleProc2) → Drain โดยใช้ Object Assembly Buffer/Diverter ในการแยกชิ้นงานไปสองเส้นทาง

ใช้แก้ปัญหาจากตัวอย่างที่ 1 — เมื่อเพิ่มสถานีขนาน 2 ตัวที่ทำงานพร้อมกัน ความสามารถในการรองรับ (Throughput) จะเพิ่มขึ้นเกือบเท่าตัว

-- Method ผูกกับ Diverter เพื่อเลือกเส้นทางแบบสลับกัน (round robin)
is
  var target: object;
do
  if Diverter.NumMUsProcessed mod 2 = 0 then
    target := SingleProc1;
  else
    target := SingleProc2;
  end;
  @.MU:=target;

ตัวอย่างที่ 3: เก็บสถิติ Throughput ด้วย Method

ผูก Method นี้ไว้ที่ Drain.ExecuteAt.Entrance เพื่อนับจำนวนชิ้นงานที่ผลิตสำเร็จต่อชั่วโมง

is
do
  GlobalCounter := GlobalCounter + 1;
  if EventController.SimTime > 0 then
    print "Throughput: ", GlobalCounter / (EventController.SimTime / 3600), " pcs/hour";
  end;

ต้องสร้างตัวแปร GlobalCounter เป็น Object ประเภท Variable (ตั้งค่าเริ่มต้น = 0) ไว้ก่อนใช้งาน
