ตัวอย่างที่ 1: สายการผลิตเดี่ยว (Single Line)

เกี่ยวข้องกับ Basic บทที่ 4

โครงสร้าง: Source → Buffer → Station → Drain

  • Source: สร้างชิ้นงานทุก 6 วินาที (Interval = 6s)
  • Buffer: ความจุ 10 ชิ้น
  • Station: เวลาแปรรูป 8 วินาที/ชิ้น

คำถามฝึกคิด: เพราะ Station ใช้เวลานานกว่า Source ผลิต (8s > 6s) จะเกิดอะไรขึ้นกับ Buffer เมื่อรันไปนานๆ?

เฉลย: Buffer จะเต็มเรื่อยๆ เพราะ Station ระบายชิ้นงานออกช้ากว่าที่ Source ป้อนเข้ามา สุดท้าย Source จะถูก Block — นี่คือตัวอย่างคอขวด (Bottleneck) แบบง่ายที่สุด

ตัวอย่างที่ 2: สายการผลิตคู่ขนาน (Parallel Stations)

เกี่ยวข้องกับ Intermediate บทที่ 1 และ Advanced บทที่ 2

โครงสร้าง: Source → (Station1 / Station2) → Drain โดยใช้ Object ประเภท Sorter แยกชิ้นงานไปสองเส้นทาง

Method ผูกกับ Sorter เพื่อเลือกเส้นทางแบบสลับกัน (round robin) — ใช้ตัวแปรนับรอบแยกต่างหาก (RoundRobinCounter เป็น Object ประเภท Variable) แทนการอิงค่าสถิติภายในของ Sorter เขียนด้วย SimTalk 2.0 syntax ที่ยืนยันแล้ว:

->void;
var target
RoundRobinCounter := RoundRobinCounter + 1
if RoundRobinCounter mod 2 = 0
    target := Station1
else
    target := Station2
end
@.MU := target

ตัวอย่างที่ 3: เก็บสถิติ Throughput ด้วย Method

เกี่ยวข้องกับ Advanced บทที่ 2 และ บทที่ 3

ผูก Method นี้ไว้ที่ Drain.ExecuteAt.Entrance เพื่อนับจำนวนชิ้นงานที่ผลิตสำเร็จต่อชั่วโมง (ต้องสร้างตัวแปร GlobalCounter เป็น Object ประเภท Variable ผ่าน .Node("Variable") ไว้ก่อนใช้งาน — ดู Advanced บทที่ 3)

->void;
GlobalCounter := GlobalCounter + 1
if EventController.SimTime > 0
    print "Throughput: " + to_str(GlobalCounter / (EventController.SimTime / 3600)) + " pcs/hour"
end
