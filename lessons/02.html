Plant Simulation Tutorial

02. คอขวด และ ParallelStation

วัตถุประสงค์การเรียนรู้

  1. สร้าง / สลับ Frame แสดงชื่อ object และย้าย ลบ แทรก object ใน Frame ได้
  2. วาง Display และ Chart (Resource Statistics) ด้วยการลาก object มาวาง แล้วอ่านผลได้
  3. หาคอขวดจากสีใน Chart (Working / Blocked / Waiting) ได้
  4. แก้คอขวดด้วยการเพิ่มเครื่องขนาน หรือ ParallelStation และตั้ง Start Processing When Full ให้ถูกได้
⬇ ดาวน์โหลดไฟล์ของบท

ขั้นที่ 3: ตั้ง 3D Chart ให้ยืนอยู่หลังไลน์

Model2 › Chart: แท็บ Display (ซ้าย) · ปุ่ม 3D › Transformation (ขวา)

  1. 1Category = 3D Chart — ช่อง Display in Frame ขึ้นเครื่องหมายถูก ☑ ให้เอง
  2. 2ปุ่ม 3D มุมซ้ายล่าง — เปิดหน้าต่าง 3D แท็บ Transformation
  3. 3Rotation: Angle = 90, Axis X = 1 — หมุน 90 องศารอบแกน X แผ่นกราฟจึงตั้งขึ้นจากพื้น
  4. 4Position Z = 4 m — ยกกราฟขึ้นจากพื้น (X, Y = ตำแหน่งบนพื้น)
  5. 5Apply แล้ว OK — ดูผลในมุมมอง 3D (ขั้นที่ 5)
ค่าจริงใน Model2: X = 11 m, Z = 4 m, หมุน 90 องศารอบแกน X — ค่า Y เป็นเลขเล็กมาก (เกือบ 0) เพราะเศษจากการคำนวณ

  1. 1Station — เครื่อง 1 ช่อง ทำทีละชิ้น
  2. 2ParallelStation — เครื่องหลายช่อง ทำหลายชิ้นพร้อมกัน
  3. 3วางแทน Station3 ต่อ Connector เข้า 1 ออก 1
ต่อเส้นน้อยลง: 2 เครื่องแยกใช้ Connector เข้า–ออก 4 เส้น ParallelStation ตัวเดียวใช้ 2 เส้น (Model3 8 เส้น → Model4 6 เส้น)

ขั้นที่ 8: ตั้งจำนวนช่อง และ When Full

ดับเบิลคลิก ParallelStation › แท็บ Attributes

  1. 1X-Dimension = 2 — จำนวนช่องแนวนอน
  2. 2Y-Dimension = 1 — จำนวนแถว → 2 × 1 = 2 ช่อง
  3. 3Start Processing When Full — ช่องหน้าชื่อมีเครื่องหมายถูก ☑ มาตั้งแต่แรก (ค่าเริ่มต้น) = รอให้ชิ้นงานเข้าครบทุกช่องก่อนเริ่มทำ
ตามคู่มือ: ค่าเริ่มต้นของ Start Processing When Full คือมีเครื่องหมายถูก ☑ (เปิด) ชิ้นใหม่เข้าได้เมื่อชุดเดิมทำเสร็จและออกหมดแล้ว — ParallelStation ที่วางใหม่จาก Toolbox มีค่าเริ่มต้น 2 × 2 = 4 ช่อง ในไฟล์นี้ตั้งเป็น 2 × 1

ขั้นที่ 9: ตั้งเวลาทำงานของ ParallelStation

  1. 1Times — แท็บตั้งเวลา
  2. 2Processing Time = 0:20 — ทุกช่องใช้ 20 วินาทีต่อชิ้น
คิดเร็ว: 2 ช่อง × 20 วินาที = เฉลี่ย 10 วินาทีต่อชิ้น เท่ากับเครื่องอื่นในไลน์ ควรได้ ~354 ชิ้น/ชม. เหมือน Model3

ขั้นที่ 10: Model4 — ได้แค่ 177 ทั้งที่มี 2 ช่อง

  1. 1ParallelStation — ช่อง Start Processing When Full มีเครื่องหมายถูก ☑ (เปิด)
  2. 2FG = 177 — เท่ากับ Model2 ที่มีเครื่องเดียว 20 วินาที
ทำไม: ต้องรอชิ้นที่ 2 เข้ามาให้ครบก่อนเริ่ม และรับชุดใหม่ได้เมื่อออกหมดแล้ว 2 ช่องจึงทำงานเหมือนเครื่องเดียว

ขั้นที่ 10: 3D Chart — ParallelStation รอครึ่งหนึ่งของเวลา

  1. 1Station1–2 สีเหลือง — Blocked ~49% ส่งต่อไม่ได้
  2. 2ParallelStation — เขียว 50% เทา 50% = รอชิ้นให้ครบ 2 ช่อง
  3. 3Station4–5 สีเทา — Waiting ~51% รองาน
  4. 4ชื่อสถานะ — ดูสีจาก legend ด้านขวา
ต่างจาก Model2: คอขวดใน Model2 เขียวเต็มแท่ง แต่ ParallelStation ที่เปิด When Full ☑ เสียเวลาครึ่งหนึ่งไปกับการรอ

ขั้นที่ 11: Model5 — เอาเครื่องหมายถูกหน้า When Full ออก

  1. 1Start Processing When Full — คลิกช่องสี่เหลี่ยมด้านหน้าให้เครื่องหมายถูกหายไป ☐ (ปิด) = เริ่มทำทันทีที่มีชิ้นเข้าช่อง ไม่ต้องรอให้ครบ
  2. 2FG = 354 — เท่ากับ 2 เครื่องแยกใน Model3 แต่ต่อเส้นน้อยกว่า
จำง่าย: ParallelStation ที่ทำงานต่อเนื่องในไลน์: ปิด When Full (☐ ไม่มีเครื่องหมายถูก) · เปิดไว้ (☑) เมื่อต้องการให้ทำพร้อมกันทั้งชุด เช่น เตาอบ

ขั้นที่ 11: Chart ก่อน–หลัง ปิด When Full

3D Chart: Model4 (ซ้าย) · Model5 (ขวา)

  1. 1เปิด When Full ☑ — ParallelStation ทำงาน 50% · ได้ 177 ชิ้น/ชม.
  2. 2ปิด When Full ☐ — ทำงาน 99% ทุกแท่งเขียว · ได้ 354 ชิ้น/ชม. (+100%)

เพิ่มช่องแล้ว FG ไม่เพิ่มคอขวดย้ายไปเครื่องอื่นแล้ว ดูสีใน Chart

คำถามฝึกคิด: ในลองเอง 2 ตั้ง ParallelStation เป็น 2 ช่อง × 0:10 และเปิด When Full ☑ เครื่องเร็วขึ้น 2 เท่า แต่ทำไม FG ได้แค่ 236 น้อยกว่าไลน์ปกติ (355)?
เฉลย: เพราะเมื่อเปิด When Full ☑ ParallelStation ต้องรอชิ้นงานเข้าให้ครบทุกช่องก่อนเริ่มทำ และรับชุดใหม่ได้เมื่อชุดเดิมออกหมดแล้ว จึงเสียเวลาไปกับการรอ (เหมือน Model4 ที่ทำงานแค่ 50%) — ถ้าปิด When Full ☐ จะเริ่มทำทันทีที่มีชิ้นเข้าช่อง แบบเดียวกับ Model5 ที่ได้ 354 ชิ้น/ชม.
