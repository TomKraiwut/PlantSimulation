Plant Simulation Tutorial

3. อิเล็กทรอนิกส์ (Electronics / SMT)

วัตถุประสงค์การเรียนรู้

  1. เห็นตัวอย่างการจำลองสาย SMT ที่ต้องการความแม่นยำและ Failure สูง
  2. เข้าใจว่าทำไมอุตสาหกรรมอิเล็กทรอนิกส์ให้ความสำคัญกับ Yield/Rework

บริบทอุตสาหกรรม

สาย SMT (Surface-Mount Technology) วางชิ้นส่วนอิเล็กทรอนิกส์ขนาดเล็กมากลงบนแผ่น PCB ด้วยความเร็วสูงและความแม่นยำสูง ปัญหาหลักคือ Yield (สัดส่วนแผ่นที่ผ่านมาตรฐาน) ไม่ใช่แค่ Throughput

โจทย์ตัวอย่าง

สาย SMT มี Reject rate 3% ที่สถานีตรวจสอบ (AOI) ต้องการรู้ว่าถ้าเพิ่มสถานี Rework คู่ขนาน จะช่วยเพิ่ม Throughput สุทธิ (แผ่นที่ผ่านจริง) เท่าไหร่

โครงสร้างโมเดล

  • Station ต่อกันจำลองสถานี Print Paste → Place Component → Reflow → AOI
  • ที่ AOI ใช้ Sorter แยกแผ่นที่ Reject ออกไปเข้าสถานี Rework แยกต่างหาก (Object Reference: Material Flow)
  • ตั้ง Failure ที่สถานี Place Component ให้ถี่กว่าสถานีอื่น (หัวจับชิ้นส่วนสึกบ่อย) (Intermediate บทที่ 4)
  • ใช้ Method ผูกกับ Sorter ตัดสินใจ Reject/Pass แบบสุ่มตามอัตราจริง (Advanced บทที่ 2)
คำถามฝึกคิด: เพิ่มสถานี Rework คู่ขนานแล้ว Throughput สุทธิเพิ่มขึ้น แต่ยังไม่คุ้มกับต้นทุนที่เพิ่ม ควรดูตัวเลขอะไรเพิ่มก่อนตัดสินใจ?
เฉลย: ควรดู Utilization ของสถานี Rework ที่เพิ่มมาด้วย (จาก Statistics) — ถ้า Utilization ต่ำมาก แปลว่าลงทุนเกินความจำเป็น ทางที่คุ้มกว่าอาจเป็นการลด Reject rate ที่ต้นทาง (แก้ที่ Place Component) แทนที่จะเพิ่มสถานีรับมือปลายทาง
