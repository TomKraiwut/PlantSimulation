Plant Simulation Tutorial

2. Information Flow Objects

วัตถุประสงค์การเรียนรู้

  1. เข้าใจว่า Object สาย Information Flow แต่ละตัวมีไว้ทำอะไร
  2. รู้ว่าจะไปดูรายละเอียดเชิงลึกของแต่ละตัวต่อได้จากบทไหน

Object กลุ่มนี้ไม่ใช่เส้นทางที่ชิ้นงานไหลผ่าน แต่เป็นตัวเก็บข้อมูลและตรรกะที่ควบคุมพฤติกรรมของ Object อื่น ทั้งหมดอยู่ใต้ .InformationFlow และมีกับดัก auto-deref ร่วมกัน — รายละเอียดเต็มที่ Advanced บทที่ 3

Method

Object ที่เก็บโค้ด SimTalk เรียกทำงานเองหรือผูกกับเหตุการณ์ของ Object อื่นได้ — ดู Advanced บทที่ 1 และ บทที่ 2

Variable

ตัวแปรเก็บค่าเดี่ยว อ่าน/เขียนได้ทั้งจาก GUI และสคริปต์ ใช้บ่อยเป็นตัวนับสะสมหรือค่าคงที่ของโมเดล เช่น Constraint ในโจทย์ GA

DataTable

ตารางข้อมูล 2 มิติ เข้าถึงด้วย bracket indexing [col, row] — ดู Advanced บทที่ 3

เรียก Method ซ้ำตามรอบเวลา

ไม่มี Object แยกต่างหากชื่อ Trigger ในเวอร์ชันปัจจุบันแล้ว (ชื่อจากเวอร์ชันเก่า) — ทำ Method ให้ทำงานซ้ำตามรอบเวลาโดยไม่ต้องผูกกับ เหตุการณ์ของ Object อื่นได้ผ่านกลไกจัดตารางเวลาของ EventController แทน — ดู Advanced บทที่ 2
