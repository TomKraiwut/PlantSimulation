Plant Simulation Tutorial

1. Material Flow Objects

วัตถุประสงค์การเรียนรู้

  1. จำ Object สาย Material Flow ที่ใช้บ่อยที่สุดและหน้าที่ของแต่ละตัวได้ไว
  2. ทำตามสาธิตสั้นๆ ของแต่ละ Object เพื่อเห็นพฤติกรรมจริงด้วยตาตัวเอง

Object กลุ่มนี้คือสิ่งที่ชิ้นงานไหลผ่านโดยตรง ครอบคลุมทั้งที่เรียนไปแล้วในระดับ Basic/Intermediate รวมไว้ที่เดียวเป็นแหล่งอ้างอิงเร็วๆ

Source

จุดกำเนิดชิ้นงาน (MU) เข้าสู่ระบบ ควบคุมด้วย Interval

ลองสาธิต: วาง Source เดี่ยวๆ ต่อ Drain ตั้ง Interval := 2 วินาที รันแล้วดู Drain.StatDeleted เพิ่มขึ้นทุก 2 วินาที — ยืนยันว่า Interval คุมจังหวะการผลิตจริง

Line

สายพานลำเลียงระหว่างสถานี มีความเร็ว/ความยาวจำลองเวลาขนส่งจริง ต่างจากการเชื่อม Object ตรงๆ ที่ไม่มีเวลาขนส่งเลย

ลองสาธิต: เพิ่ม Line ยาว 50m ความเร็ว 1m/s คั่นกลาง Source-Drain จะเห็นชิ้นงานใช้เวลาประมาณ 50 วินาทีบน Line ก่อนถึง Drain

SingleProc

สถานีประมวลผล 1 หัว ควบคุมด้วย ProcTime — ดูรายละเอียดเต็มที่ Basic บทที่ 3

Buffer / Store

พักชิ้นงานคอยส่งต่อ — Buffer แบบ FIFO ธรรมดา, Store มีตำแหน่งจัดเก็บย่อยหยิบสุ่มได้ ดูเปรียบเทียบที่ Intermediate บทที่ 1

Drain

จุดทำลายชิ้นงานเมื่อออกจากระบบ (สินค้าสำเร็จรูป) — StatDeleted คือตัวนับสะสมที่ใช้บ่อยที่สุดเวลาวัด Throughput

EventController

นาฬิกาของโมเดล ต้องมีเสมอ 1 ตัวต่อโมเดล อ่านเวลาปัจจุบันด้วย SimTime

AssemblyStation

รวมชิ้นงานจากหลายทางเข้าเป็นชิ้นเดียว รอครบทุกอินพุตก่อนประมวลผล — ดูตัวอย่างที่ Intermediate บทที่ 1

Track + Transporter

เส้นทางให้พาหนะขับเคลื่อนเอง — ต้องตั้ง Destination และ AutomaticRouting ให้ Transporter ถึงจะวิ่งจริง (กับดักที่พบบ่อย ดูเต็มๆ ที่ Advanced บทที่ 4)

Diverter

แยกเส้นทางชิ้นงานออกเป็นหลายทาง มักผูก Method ตัดสินใจว่าจะส่งไปทางไหน (ดูตัวอย่างที่ Example File)
