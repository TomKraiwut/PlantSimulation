Plant Simulation Tutorial

5. หุ่นยนต์และการขนย้าย

วัตถุประสงค์การเรียนรู้

  1. แยกการใช้งาน PickAndPlace, Track (AGV) และ AGVPool+Marker (AMR) ได้
  2. เลือกระหว่างระบบขนย้ายแบบรางกับแบบอิสระให้เหมาะกับสถานการณ์ได้

อ้างอิงเฟรม Model_PickAndPlace, Model_AGV, Model_Basic_AMR — แขนกลหยิบวาง และยานพาหนะขนย้ายอัตโนมัติสองยุค (AGV แบบราง กับ AMR แบบอิสระ)

PickAndPlace — แขนกลหยิบวาง

PickAndPlace ย้ายชิ้นงานจากจุดหนึ่งไปอีกจุดหนึ่งแบบไม่ต่อเนื่อง (หยิบ → เคลื่อนที่ → วาง) ต่างจาก Conveyor ที่ลำเลียงต่อเนื่อง เฟรม Model_PickAndPlace มี 4 ชุดวางคู่กันสาธิตรูปแบบการใช้งานต่างกัน

Tip: เวลารวมของ PickAndPlace มักเป็นคอขวดที่มองข้าม เพราะแยกเป็น 3 ช่วงเวลา (หยิบ+เคลื่อนที่+วาง) รวมกัน — ลองแตกดูทีละช่วงใน Statistics ก่อนสรุปว่าเครื่องจักรช้าไม่ใช่ที่แขนกล

Track — AGV แบบเดินตามราง (ยุคเก่า)

เฟรม Model_AGV ใช้ Object Track กำหนดเส้นทางเดินรถตายตัวบนพื้น แล้วให้ยานพาหนะวิ่งตาม เส้นทางนั้น จุดขึ้น-ลงสินค้าทำผ่าน PickAndPlace ที่ผูกอยู่บน Track — เหมาะกับโรงงานที่เส้นทางขนย้ายคงที่ ไม่เปลี่ยนบ่อย (กับดัก Destination/AutomaticRouting ที่พบบ่อยกับ Transporter ดูที่ Advanced บทที่ 4)

AGVPool + Marker — AMR แบบอิสระ (ยุคใหม่)

เฟรม Model_Basic_AMR ใช้แนวคิดต่างจาก Track: Marker คือจุดอ้างอิงลอยตัวในพื้นที่ (ไม่ใช่ เส้นทางตายตัว) ส่วน AGVPool คือกลุ่มยานพาหนะที่คำนวณเส้นทางเดินไปมาระหว่าง Marker เองแบบไดนามิก

TrackAGVPool + Marker
เส้นทางตายตัว ต้องวาดไว้ล่วงหน้าคำนวณเองระหว่าง Marker แต่ละจุด
ความยืดหยุ่นต่ำ — ย้ายจุดต้องแก้ Trackสูง — ย้าย Marker ได้อิสระ
เหมาะกับเส้นทางขนย้ายคงที่ ปริมาณสูงผังพื้นที่เปลี่ยนบ่อย

เฟรมนี้ยังสาธิตรูปแบบ Method วงจรชีวิตมาตรฐาน 3 ตัว — INIT/RESET/ENDSIM — ผูกกับจังหวะเริ่ม/รีเซ็ต/จบของ EventController พร้อมตัวแปร Total_Distance สะสมระยะทางที่ AMR วิ่งทั้งหมด

รูปแบบนี้ใช้ซ้ำได้ทั่วไป: การผูก Method ชื่อ INIT/RESET/ENDSIM เข้ากับจังหวะของ EventController ใช้ได้กับโมเดลไหนก็ได้ ไม่ใช่แค่ AMR — ดูการผูก Method กับเหตุการณ์เต็มๆ ที่ Advanced บทที่ 2
คำถามฝึกคิด: ถ้าต้องขยายโกดังเพิ่มโซนใหม่บ่อยๆ ควรเลือก Track หรือ AGVPool+Marker?

เฉลย: AGVPool + Marker เพราะแค่เพิ่ม Marker จุดใหม่โดยไม่ต้องวาดเส้นทางเชื่อมใหม่ทั้งหมด
