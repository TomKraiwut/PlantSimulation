Plant Simulation Tutorial

1. พื้นฐานสายการผลิต

วัตถุประสงค์การเรียนรู้

  1. อ่านโครงสร้าง Object ในเฟรม Model_Station/Model_ParallelStation ของไฟล์สอนจริงได้
  2. รู้ว่าเมื่อไหร่ควรใช้ ParallelStation แทน Station เดี่ยวหลายตัว

อ้างอิงเฟรม Model_Station และ Model_ParallelStation จากไฟล์สอนต้นฉบับของ Siemens — Object พื้นฐานที่สุดที่ต้องรู้ก่อนสร้างโมเดลจำลองการผลิตแรก ดูรายละเอียด Object แต่ละตัวเต็มๆ ได้ที่ Basic บทที่ 01

Object ในเฟรมต้นฉบับ: Model_Station มี EventController, Source ×2, Station ×6, Drain ×2, Display ×3, Chart, Connector ×8 — Model_ParallelStation มี EventController, Source ×2, Conveyor, ParallelStation ×4, Buffer, Drain, Display ×4, Chart, Connector ×7

สายการผลิตต่อเนื่องหลายสถานี

ในเฟรม Model_Station นอกจากสาย Source → Station → Drain เดี่ยวๆ แล้ว ยังมีสายที่ต่อ Station ถึง 4 ตัวเรียงกัน (Source1 → Station1 → Station2 → Station3 → Drain1) เพื่อสาธิตว่าสายการผลิตจริงมักมีหลายสถานี ต่อเนื่องกัน ไม่ใช่แค่สถานีเดียว — ผลลัพธ์ Throughput รวมของสายจะถูกจำกัดด้วยสถานีที่ช้าที่สุดในสาย (คอขวด)

เมื่อ Station เดียวไม่พอ: ParallelStation

เฟรม Model_ParallelStation สาธิตทางเลือกเมื่อจุดหนึ่งในสายการผลิตต้องมี "เครื่องจักรทำงานแบบเดียวกันหลายเครื่อง พร้อมกัน" แทนที่จะวาง Station หลายตัวแล้วต้องมี Sorter แยกเส้นทางเอง ParallelStation คือ Object เดียวที่มีคิว รับงานได้จากหลายเครื่องจักรภายในตัวมันเอง กำหนดจำนวน "เครื่อง" ในตัวเดียวได้ที่แท็บ Attributes

Object เพิ่มเติมในเฟรมนี้ใช้ทำอะไร
Conveyorลำเลียงชิ้นงานแบบต่อเนื่อง (มีความเร็ว/ความยาว) ต่างจาก Connector ที่เป็นแค่เส้นเชื่อมตรรกะ
Bufferจุดพักชิ้นงานแบบมีความจุจำกัด เมื่อสถานีถัดไปไม่ว่าง
คำถามฝึกคิด: ถ้ามี Station เดี่ยว 3 ตัวขนานกัน (ต้องมี Sorter + Connector เชื่อมแยก 3 เส้น) เทียบกับ ParallelStation 1 ตัวที่ตั้งค่า 3 เครื่องภายใน อะไรต่างกัน?

เฉลย: ผลลัพธ์ Throughput ใกล้เคียงกัน แต่ ParallelStation สร้าง/แก้ไขง่ายกว่ามาก (ไม่ต้องวาง Sorter หรือคุม Connector หลายเส้น) เหมาะกับกรณีเครื่องจักรเหมือนกันทุกประการ ส่วน Station เดี่ยวหลายตัวเหมาะกับกรณีที่แต่ละเครื่องมีเงื่อนไข/เวลา ไม่เท่ากัน
